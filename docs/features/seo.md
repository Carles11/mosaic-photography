# Feature: SEO & AI Search

> SEO is a first-class concern. Every public page needs metadata + JSON-LD.

## Files

| File | Role |
|---|---|
| `src/app/layout.tsx` | Root metadata, site-level JSON-LD, critical CSS, font preloads |
| `src/components/seo/JsonLdSchema.tsx` | Reusable JSON-LD component |
| `src/utils/structuredData.ts` | JSON-LD data builders for gallery/homepage |
| `src/utils/faqStructuredData.ts` | FAQPage schema builder |
| `src/app/constants/faqSections.ts` | FAQ content (crawlable copy + schema source) |
| `next-sitemap.config.js` | Sitemap + robots.txt config |
| `scripts/generate-image-sitemap.ts` | Builds `public/image-sitemap.xml` from Supabase |
| `scripts/generate-collection-sitemap.ts` | Builds `public/collection-sitemap.xml` |
| `scripts/generate-sitemap-0.ts` | Builds main page sitemap |
| `public/robots.txt` | Crawler instructions |

## Page Metadata Checklist

Every public page must export:

```typescript
export const metadata: Metadata = {
  title: "Page Title",
  description: "Page description (150–160 chars)",
  alternates: { canonical: "https://www.mosaic.photography/page-path" },
  openGraph: {
    title: "OG Title",
    description: "OG description",
    images: [{ url: "/images/og-image.jpg", width: 1200, height: 630 }],
  },
  twitter: { card: "summary_large_image", title: "...", description: "..." },
};
```

Dynamic pages (e.g., photographer pages) use `generateMetadata`:
```typescript
export async function generateMetadata({ params }): Promise<Metadata> {
  const photographer = await fetchPhotographerByIdSSR(params.surname);
  return { title: photographer.name, ... };
}
```

## JSON-LD Schemas

### Site-level (in `layout.tsx`)
- `WebSite` — site name, URL, description
- `Organization` — name, logo, sameAs social links

### Page-level schemas

| Page | Schema type | Where |
|---|---|---|
| Homepage | `WebPage` + `ImageGallery` | `HomeClientWrapper.tsx` |
| Photographer page | `Person` | `photographers/[surname]/page.tsx` |
| FAQ page | `FAQPage` | `FaqClientWrapper.tsx` |
| App landing | `WebPage` + `ImageGallery` (screenshots) | `app/page.tsx` |
| Each image | `ImageObject` | `ImageWrapper.tsx` |

### JsonLdSchema Component

```tsx
import JsonLdSchema from '@/components/seo/JsonLdSchema';

// Supported types: "WebSite" | "WebPage" | "Organization" | "ImageGallery" | "ImageObject"
<JsonLdSchema
  type="Person"
  name="Anne Brigman"
  url="https://www.mosaic.photography/photographers/brigman"
  description="..."
/>
```

For custom schemas, use inline `<script type="application/ld+json">` in the page.

## ImageObject Schema (per-image SEO)

`ImageWrapper.tsx` emits for each image:
```json
{
  "@type": "ImageObject",
  "name": "Image title",
  "description": "...",
  "contentUrl": "https://cdn.mosaic.photography/...",
  "license": "https://creativecommons.org/publicdomain/mark/1.0/",
  "acquireLicensePage": "https://www.mosaic.photography/legal/credits",
  "creditText": "Photographer Name",
  "encodingFormat": "image/webp",
  "width": 1200,
  "height": 800
}
```

## Sitemaps

| Sitemap | Contents | Generated by |
|---|---|---|
| `/sitemap.xml` | Index of all sitemaps | `next-sitemap.config.js` |
| `/sitemap-0.xml` | All photographer + page URLs | `scripts/generate-sitemap-0.ts` |
| `/image-sitemap.xml` | All WebP image URLs with metadata | `scripts/generate-image-sitemap.ts` |
| `/collection-sitemap.xml` | Public collection URLs | `scripts/generate-collection-sitemap.ts` |

Sitemaps are generated at build time via `postbuild` in `package.json`. Requires Supabase env vars.

## Performance / Core Web Vitals

Current scores (Google PageSpeed Insights):
- Desktop: 100 / 100 / 100 / 100
- Mobile: 97 / 100 / 100 / 100

Key strategies:
- Critical CSS inlined in `layout.tsx` (`critical-above-the-fold.css`)
- Base CSS inlined via `?raw` import
- Non-critical CSS loaded async via `NonCriticalCSSLoader.tsx`
- Trade Gothic fonts preloaded from CDN with `font-display: swap`
- `preconnect` + `dns-prefetch` for CDN and Supabase
- All images: `next/image` with lazy loading, WebP, explicit dimensions
- No manual image preloading (intentionally removed)

## AI Search Engine Optimizations

- `llms.txt` at root — machine-readable site summary for AI crawlers
- Bot detection in `middleware.ts` — known AI crawlers get `skip_age_modal=1` cookie
- Detected bots: `perplexitybot`, `anthropic`, `claude`, `gptbot`, `oai-searchbot`, `chatgpt`, `cohere`, `amazonbot`, etc.
- FAQ content (`faqSections.ts`) targets long-tail queries about public domain, licensing, image SEO
- Agent access: `.md` suffix on photographer URLs returns unstyled Markdown biography

## Non-Indexed Routes

These must NOT be indexed:
```typescript
// src/app/auth/layout.tsx
export const metadata = { robots: { index: false, follow: false } };
```

Also: `src/app/not-found.tsx` sets `robots: { index: false, follow: false }`.
