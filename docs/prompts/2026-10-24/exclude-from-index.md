The CDN `https://cdn.mosaic.photography` has no robots.txt today (403), so crawlers can fetch
every file. Write a script (same env/client setup as `scripts/generate-image-sitemap.ts`,
read-only) that selects `base_url, filename` where `exclude_from_index = true` and writes
`cdn-robots/robots.txt`:

```
# robots.txt for cdn.mosaic.photography — generated by scripts/generate-cdn-robots.ts
# Images kept on www.mosaic.photography but excluded from search indexes (2026-10-24).
User-agent: *
Allow: /
Disallow: /<path from base_url>/*/<filename stem>.webp
...one Disallow line per flagged image...
```

- `<path from base_url>` = the URL path of `base_url` (e.g.
  `/mosaic-collections/public-domain-collection/von-gloeden`). The `*` covers every size folder
  (`w400`…`w1600`, `originalsWEBP`). `<filename stem>` = filename without extension. Google and
  Bing both support `*` in Disallow.
- If 0 rows: print an error and `process.exit(1)` (means the migration has not run).
- Do not run it now (the column does not exist yet). Carles runs
  `npx tsx scripts/generate-cdn-robots.ts` after the migration, commits `cdn-robots/robots.txt`
  and uploads it to the S3 bucket root by hand. Do not add a package.json script.
